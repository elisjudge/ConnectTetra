# ConnectTetra

A reinforcement model to learn a modified game of Connect Four.


## Project Aims

* Train two AI players to play a novel game competently within a reasonable time cost.
* Analyse the learning process of the AI and report findings.

## Motivation

Connect Four is a solved game. 


I have fond memories of playing Connect Four against family members. 

## Game Rules

### Overview

Like the traditional game, ConnectTetra begins on a 6X7 game board with each player taking turns to place a single piece in a column slot. Each piece will automatically drop to the bottom-most unoccupied space in the column. To win the game, a player must connect four of their pieces in a straight line spanning horizontally, vertically, or diagonally across the board.
